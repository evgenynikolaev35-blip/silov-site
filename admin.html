Шаг 1

Вход

Чтобы сохранять изменения, нужен ключ доступа GitHub. Он хранится только в этом браузере и никуда, кроме GitHub, не отправляется.

Без ключа доступен только просмотр настроек.

Как получить ключ доступа (один раз, 2 минуты)
  1. Войдите на github.com под аккаунтом владельца сайта.
  2. Откройте Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Название: silov-site admin. Срок действия: 1 год.
  4. Repository access → Only select repositories → выберите silov-site.
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Нажмите Generate token, скопируйте ключ и вставьте сюда. Ключ даёт доступ только к файлам этого сайта.

Шаг 2

Блоки сайта

Включайте и выключайте разделы. Пункты меню скрываются вместе с блоками.

Шаг 3

Фотографии

Выберите файл с телефона или компьютера — фото автоматически уменьшится до 1600 px и сожмётся. Подойдут JPG, PNG, HEIC (с iPhone).

Изменений нет.
